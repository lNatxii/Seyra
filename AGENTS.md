# Code language

- Use English for identifiers (variables, functions, methods, classes, namespaces and file names), code comments, technical diagnostics, tool descriptions and assistant system instructions in `Backend/` and `SeyraUnity/`.
- Spanish is allowed in deliberately localized user interface text, conversation responses and localization/test data. Keep language-dependent comparisons consistent with the messages they inspect.
- Preserve Unity serialized references when renaming fields, classes or assets; use serialization migration attributes when needed.
- Do not modify `SeyraOld/` as part of work on Seyra unless explicitly requested.
